# Calculator Android — Scientific Calculator

Offline-first dark and lime scientific calculator, packaged for Android with Capacitor.

- App version: `0.2.3`
- Android application ID: `app.calculator.offline`
- Display label: `Calculator`
- Editable UI: `web/`
- Generated web output: `www/` (regenerated by `npm run build`)

## Quick start

Requirements: Node.js 22+, npm. For native Android packaging: JDK 21, Android SDK API 35, Build Tools 35.0.0 and network access for Gradle/Maven dependencies.

```sh
npm install
npm test
npm run build
npm run android:doctor
npm run android:build:debug
```

## Automated quality checks and AI review

- The existing `.github/workflows/ci.yml` workflow runs regression tests and builds the web application for pull requests and pushes to `main`, and daily at 19:00 Bangladesh time (13:00 UTC).
- `.coderabbit.yaml` defines evidence-first AI review instructions for the Calculator project.
- `AI_REVIEW_FEEDBACK_LOOP.md` documents how an automation run should inspect review comments, verify findings, make bounded fixes, and stop rather than endlessly looping. Review evidence is valid only when its commit SHA matches the PR's current head SHA; older reviews do not validate newer commits.
- `AGENTS.md` requires application changes to use a topic branch and pull request, with tests and reviewer feedback checked before merge.
- The repository owner has installed/authorized the CodeRabbit GitHub App. A configuration file alone does not prove that a completed review occurred; verify actual review findings or review submission on an open PR. For forks/new repositories, install the App and grant repository access separately.

## Project structure

- `web/` — source HTML, CSS and calculator logic
- `tests/` — regression tests
- `scripts/` — build, Android diagnostics and SDK bootstrap helpers
- `.github/workflows/android-debug-apk.yml` — manually dispatched Android build; requires explicit SDK-license acknowledgement
- `.github/workflows/ci.yml` — automated syntax checks, regression tests and web-build checks; also scheduled daily
- `AGENTS.md` — project rules for coding agents
- `IMPLEMENTATION_BLOCKER_REPORT.md` — build evidence and remaining release-readiness items
- `AI_REVIEW_FEEDBACK_LOOP.md` — bounded review-and-correction protocol

## Security

Never commit a personal access token (PAT), OAuth token, password, signing key, or secret. Use authenticated integrations and GitHub Actions secrets where needed. Revoke any token pasted into a chat if it has not already been revoked.
